Architectural Integrity & Zero Trust

Understand how Imava protects your data using mathematical guarantees, hardware TEE modules, and zero-network isolation.

What is Imava?

Imava is a free, open-source (GPL-3.0), 100% offline Android gallery application developed as a privacy-first alternative to cloud-dependent and tracking-heavy proprietary media managers. Built entirely in Kotlin and Jetpack Compose for modern Android (Android 8.0 through Android 15), Imava combines 120Hz smooth scrolling with defense-grade security: hardware-backed AES-256-GCM vault encryption, plausible deniability Decoy PIN, multi-pass CSPRNG forensic file shredding, guest hand-off jail mode, and 0 bytes of network transmission.

🛡️ Cryptography & Security Architecture

  • Vault Cipher: AES-256-GCM (Galois/Counter Mode)
  • Key Derivation: PBKDF2 with 250,000 Rounds
  • Hardware Security: AndroidKeyStore TEE / StrongBox
  • Salt Generation: 16-Byte Cryptographic SecureRandom
  • File Shredder: CSPRNG Multi-Pass Sector Overwrite
  • Plausible Deniability: Isolated Decoy Vault Container
  • Screen Protection: Dynamic Window FLAG_SECURE

⚡ Platform & Software Specifications

  • Minimum OS: Android 8.0 Oreo (API Level 26)
  • Target OS: Android 15 (API Level 35)
  • UI Toolkit: Jetpack Compose & Material You
  • Database Engine: SQLite via Android Room
  • Network Permission: None (Zero Network Footprint)
  • Custom ROM Support: GrapheneOS, CalyxOS, LineageOS
  • Open Source License: GNU General Public License v3.0
Direct Answers

Frequently Asked Questions

Authoritative answers regarding privacy, encryption, compatibility, and device performance.

Is Imava completely offline? Does it upload anything to the cloud? ▾
Yes, Imava is 100% offline. The core application does not declare the Android INTERNET permission for photo viewing or processing. Not a single photo, video, tag, facial recognition embedding, or telemetry byte ever leaves your device. All SQLite Room indexing and ML text recognition occur strictly on-device.
How does the Hidden Vault hardware encryption work? ▾
Media moved to Imava's vault is encrypted at rest using AES-256-GCM authenticated encryption. Encryption keys are securely derived via PBKDF2 with 250,000 iterations and protected inside your phone's hardware security module (AndroidKeyStore TEE or StrongBox). Unencrypted original files are securely wiped from public storage.
What is Decoy PIN mode and how does it provide plausible deniability? ▾
Decoy PIN mode provides plausible deniability if you are forced or compelled to unlock your phone. You set up a secondary Decoy PIN alongside your Master PIN. Entering your Decoy PIN smoothly unlocks a convincing, completely empty gallery—leaving no indication that a real vault exists.
What is the CSPRNG file shredder and how does it prevent file recovery? ▾
When standard apps delete a file, they simply mark the index entry as unused, leaving raw data sectors intact on flash storage where digital forensic tools can carve and salvage photos. Imava's built-in file shredder overwrites the physical sectors with cryptographically secure pseudo-random bytes (CSPRNG) prior to unlinking, rendering file recovery mathematically impossible.
What is Guest Hand-Off "Jail" Mode? ▾
Guest Hand-Off Jail Mode eliminates the panic of showing photos to friends or colleagues. You select 1 to N photos and enter Hand-Off mode. The viewer restricts horizontal paging exclusively to those chosen photos, preventing guests from swiping left or right into private media or navigating back to your gallery grid.
Does Imava work as the default camera viewer for system camera apps? ▾
Yes! Imava registers Android ACTION_VIEW intent filters for image/* and video/* MIME types. When you tap the circular thumbnail in your device's camera app or open an image from a file manager, Imava launches instantly and smoothly drops you back to your camera viewfinder upon closing.
Does Imava work on de-Googled ROMs like GrapheneOS, CalyxOS, and LineageOS? ▾
Yes. Imava has zero dependencies on Google Play Services, Firebase, or Google Mobile Services (GMS). It runs natively and securely on GrapheneOS, CalyxOS, LineageOS, DivestOS, and vanilla AOSP.
How do I back up and restore my encrypted vault? ▾
Within Vault Security Settings, tap "Export Backup 💾". This packages all encrypted ciphertexts and metadata into a standalone .imava container encrypted with a custom passphrase that you can safely transfer to a USB flash drive, external SSD, or computer, and restore on any device running Imava.
Does Imava leave behind ghost thumbnails or leaked cache files? ▾
No. Unlike standard galleries that leave cached thumbnails in Android's shared `.thumbnails` folders, Imava includes a dedicated Ghost Thumbnail & Cache Purger that zeros out residual thumbnail caches when items are vaulted or deleted.
What is EXIF GPS location fuzzing? ▾
When sharing a photo online, exposing exact GPS coordinates can reveal your home address or workplace. Imava allows you to either strip all EXIF metadata or fuzz your coordinates within a randomized 500m to 5km radius, protecting your precise location while maintaining regional context.
