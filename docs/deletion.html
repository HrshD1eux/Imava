Google Play Data Safety Requirement

Data Deletion Policy

Effective Date: October 29, 2026 · Complies with Google Play Developer Policy

1. Overview & Zero Remote Server Retention

Google Play policies require all applications to state how user accounts and data may be deleted upon request.

Key Data Fact: Imava does not store any user data on remote servers or cloud databases. We maintain zero accounts, zero authentication records, zero cloud storage, and zero telemetry logs. Consequently, there is no remote server data to delete.

2. How Users Delete On-Device Data

All media, thumbnails, database indices, and custom tags exist exclusively on your personal device hardware. You can permanently delete any or all data at any moment:

  • Deleting Individual Photos & Videos: Select any item in the timeline and tap Delete. Items moved to Trash can be permanently removed at any time.
  • Forensic Permanent Destruction (CSPRNG Shredder): Enable the Cryptographic File Shredder in Settings or Vault. When deleting media, Imava overwrites the physical NAND sectors with multi-pass cryptographically random data before unlinking the file, preventing recovery by chip carving tools.
  • Purging Ghost Thumbnails & Cache: In Settings > Storage Cleaners & Maintenance, tap Ghost Thumbnail Purger to immediately shred orphaned OS thumbnails and cached image previews.
  • Wiping Private Vault Container: Inside Hidden Vault > Vault Settings > Delete Entire Vault, you can completely erase all encrypted files, keys, and master passwords with a single confirmation.
  • Complete Application Data Removal: Open your phone's Android Settings > Apps > Imava > Storage > Clear Storage / Clear Data or simply Uninstall the app. This instantly obliterates all local SQLite Room databases, SharedPreferences, encryption keystores, and app caches.
